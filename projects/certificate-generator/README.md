# Certificate Generator

An admin tool that creates and emails attendance certificates for events and webinars.

## How it works
1. An admin logs in and opens Create Certificate.
2. They enter the attendee and event details and preview the certificate.
3. The tool generates the image, which can be downloaded or emailed.
4. The dashboard shows certificates created, emails sent and unique events.

## Features
- Admin login and dashboard with totals
- Live preview, download and send-to-email
- All Certificates list with edit
- Bulk personalised downloads using an attendee list (a shared version for several events)
- Custom fonts and layouts

## Tech
ASP.NET MVC, Entity Framework, SQL Server, image rendering, SMTP.
