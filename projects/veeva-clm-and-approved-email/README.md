# Veeva CLM E-Detailers and Approved Email

Interactive sales presentations and compliant emails for pharmaceutical teams, built to run inside Veeva CRM.

## What I build
- **CLM e-detailers:** slide-by-slide HTML5 presentations, each slide packaged as its own zip and loaded into Veeva CLM, with navigation, key messages and animations that work on iPad
- **Approved Email templates:** responsive HTML emails and reusable email fragments that reps can personalise inside Veeva Approved Email
- **Print-to-digital conversion:** turning approved print layouts (InDesign/PDF) into modular, reusable email fragments
- **Testing and upload:** checking packages in CLM and Approved Email, then preparing them for upload

## Workflow
1. Receive the approved creative and claims.
2. Break the content into slides or fragments.
3. Build and package as HTML5 zips following Veeva's rules.
4. Test on device, fix, and hand over for upload and approval.

## Tech
HTML5, CSS, JavaScript, Veeva CLM key messages, Veeva Approved Email fragments, responsive email.
