# Interactive Games Collection

Browser games I built for events, exhibitions and training sessions. They run on desktop, tablet and phone, are timed, and report scores to a leaderboard.

Games built from third-party game kits are not listed here.

| Game | What the player does | Tech |
|---|---|---|
| **Connect Four** | Plays 4-in-a-row against the computer within a time limit; points depend on speed | HTML, CSS, JavaScript |
| **Connect the Pairs** | Draws non-crossing lines between 7 matching pairs inside 90 seconds | HTML, JavaScript |
| **Maze Collector** | Moves with the arrow keys to collect the 7 correct items and avoid decoys; 2-minute timer, 3 lives, bonus dots | HTML, JavaScript |
| **Spot the Difference** | Picks one of 6 visuals and finds the differences; shows progress and a results screen | HTML, JavaScript, PHP score API |
| **Memory Match** | Flips cards to find pairs against the clock (see [Memory Match Game](../memory-match-game/)) | HTML, CSS, JavaScript |
| **Platformer Run** | Side-scrolling one-level game: jump, collect power-ups that grow the character, dodge enemies | HTML5 |
| **Escape Room** | Explores a 360-degree room, answers riddles, taps the right object to unlock three levels against a timer | 360 viewer, ASP.NET scoring |
| **Background and Frame Changer** | Takes a photo, removes the background with AI, and adds a themed frame | ASP.NET MVC, OpenCV |

## Common features
- Registration with name and email before play
- Countdown timer and speed-based scoring
- Admin leaderboard and results export
- Responsive layout, kiosk-friendly for event stands
