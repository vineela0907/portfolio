# Medical Congress Event Platform

A web platform that runs a live healthcare congress end to end: agenda, attendee check-in, live interaction and certificates.

## What it does
- **Agenda and speakers:** sessions by day and room, speaker profiles, venue information
- **Attendance:** QR-code scanner check-in for attendees at the door and in rooms
- **Live interaction:** voting/polls with a results screen for the stage, Q&A, live chat and notifications
- **Engagement:** photo gallery, videos, an escape-room game with a leaderboard, stations/activities, surveys
- **Webinar support:** API integration for online sessions
- **CME certificates:** generated per attendee after the sessions
- **Admin back office:** manage attendees, content, feature flags and dashboards

## How it works
1. Organisers load the agenda, speakers and attendees in the admin area.
2. Attendees register or are imported, then check in by QR code.
3. During sessions, moderators open a poll or question; attendees answer on their phones and results appear on the stage screen.
4. After the event, certificates and reports are generated from the same data.

## Tech
ASP.NET Core MVC, REST APIs, SQL Server, Razor views, responsive front end.
