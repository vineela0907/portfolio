# Spin the Wheel

![Spin the wheel](images/wheel.png)

A simple prize and quiz wheel for events. The visitor presses a button, the wheel spins with a ticker, and when it stops a pop-up shows the result or a question.

## Features
- Smooth CSS and JavaScript spin animation with ticker
- Pop-up result with a list of questions or prizes
- Easy to re-theme: colours, segments and content are configurable
- Works on any screen with no server needed

## Tech
Plain HTML, CSS and JavaScript.
