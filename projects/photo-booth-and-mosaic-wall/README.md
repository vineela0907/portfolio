# Photo Booth and Mosaic Wall

A photo booth where visitors take a picture, see it inside a branded frame, and print or save it. Every approved photo then becomes a tile on a large 4K mosaic wall.

## How it works
1. The visitor stands at the booth; the webcam shows a live preview.
2. They capture, retake if needed, and confirm.
3. The server places the photo inside the frame, stores it and records its details.
4. A moderator approves photos before they appear.
5. The wall screen shows approved photos as a growing mosaic; each square is one photo.

## Features
- Browser camera capture, preview, retake, save and print
- Automatic detection of the frame's transparent window at start-up
- Paged gallery, moderation gate, print counter, soft delete
- Health check and API documentation (OpenAPI)
- 4K wall display with switchable light/dark themes and placeholder tiles
- Consent-aware design: attendee consent is recorded separately

## Tech
.NET 10 Web API, SkiaSharp, EF Core and SQL Server; Next.js and React with TypeScript; static HTML wall.
