# Bilingual Email Campaigns

Responsive HTML emails in English and Arabic (right-to-left), with variants for several countries.

## Features
- Table-based layouts that work across Outlook, Gmail and mobile
- Full RTL Arabic versions
- Per-country variants from one master template
- Invitations, reminders and thank-you emails for events
- Packaged with subject and metadata files for upload to approved-email systems

## Tech
Email-safe HTML and CSS, optimised images, CSV metadata.
