# Event Registration and QR Check-in

A full event flow: landing page, registration, personal QR code, door scanner and organiser dashboard.

## How it works
1. Guests register on a responsive landing page with the agenda.
2. They receive an email with a unique QR code.
3. At the door, staff scan the code; duplicates are flagged.
4. Station scans track which activity points each guest visits (up to 10).
5. Organisers see live attendance in an admin dashboard.

## Features
- Registration, confirmation, reminder and RSVP (confirm / decline) emails
- Unique QR per guest, duplicate-scan detection
- Station tracking, action log and CSV export
- Invite, reset-password and privacy pages

## Tech
ASP.NET MVC, SQL Server, QR code generation, SMTP, responsive CSS.
